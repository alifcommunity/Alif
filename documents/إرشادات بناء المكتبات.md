### ويندوز:

1. يتم إنشاء مجلد للمكتبة يحتوي التالي:
	1. مجلد include يمكن نسخه من مجلد لغة ألف
	2. مجلد lib يحتوي alif.lib يمكن نسخه من مجلد لغة ألف
	3. ملف المكتبة مكتبة.cpp
	يتم تشغيل الطرفية x64 Native Tools Command Prompt VS  ضمن المجلد وكتابة الأمر التالي:
	```
	cl /std:c++20 /EHsc /O2 /GL /LD مكتبة.cpp /I "include" /link /LTCG /LIBPATH:"libs" alif.lib /OUT:حساب.alifd
	```
	وهذا سينتج ملف حساب.alifd حيث يتم نسخه إلى المسار الذي يمكن استيراده منه

بهذا يمكن استيراد المكتبة بنجاح.


### لينكس:

1. يتم بناء اللغة مع أعلام المشاركة مفعلة:
```
make shared=1
```

2. يتم إنشاء مجلد للمكتبة يحتوي التالي:
	1. مجلد include يمكن نسخه من مجلد لغة ألف
	2. ملف المكتبة مكتبة.cpp
	ويتم تشغيل الطرفية ضمن المجلد وكتابة الأمر التالي:
	```
	c++ -std=c++20 -O3 -shared -fPIC -I"include" مكتبة.cpp -o حساب.so
	```
	وهذا سينتج ملف حساب.so حيث يتم نسخه إلى المسار الذي يمكن استيراده منه

بهذا يمكن استيراد المكتبة بنجاح.


### ماك:

1. يتم بناء اللغة مع أعلام المشاركة مفعلة:
```
make shared=1
```

2. يتم إنشاء مجلد للمكتبة يحتوي التالي:
	1. مجلد include يمكن نسخه من مجلد لغة ألف
	2. ملف المكتبة مكتبة.cpp
	ويتم تشغيل الطرفية ضمن المجلد وكتابة الأمر التالي:
	```
	c++ -std=c++20 -O3 -shared -undefined dynamic_lookup -I"include" مكتبة.cpp -o حساب.so
	```
	وهذا سينتج ملف حساب.so حيث يتم نسخه إلى المسار الذي يمكن استيراده منه

بهذا يمكن استيراد المكتبة بنجاح.



##### مثال لملف مكتبة.cpp:
``` cpp
#include "alif.h"
  

static AlifObject* method_add(AlifObject* self, AlifObject* args) {

    long a{}, b{};

    if (!alifArg_parseTuple(args, "ii", &a, &b)) {
        return NULL;

    }

    long result = a + b;

    return alifLong_fromLong(result);
}

  

static AlifMethodDef MathMethods[] = {
    {"جمع", method_add, METHOD_VARARGS},
    {NULL, NULL} // Sentinel
};

  

static AlifModuleDef mathmodule = {
    ALIFMODULEDEF_HEAD_INIT,
    "حساب",        
    "Simple C++ math module",
    0,              
    MathMethods
};

  

ALIFMODINIT_FUNC alifInitU_mgbcny(void) {
    return alifModuleDef_init(&mathmodule);
}
```
